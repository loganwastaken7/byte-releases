# Byte: downloads

Byte is a holographic desktop assistant for Windows 10 / 11. This repo only holds the finished app; each
[release](../../releases) has the zip to download.

**Install:** download `Byte-Share-vâ€¦.zip` from the newest release, right-click it > Extract All, then double-click
`Install Byte.cmd`. Windows may say "Windows protected your PC" (the app isn't code-signed): More info > Run anyway.
A welcome window walks you through the rest; `GETTING STARTED.txt` in the zip explains everything.

**Updates:** Byte checks here once a day and asks before installing a new version. He only installs a download whose
SHA-256 matches the `.sha256` file next to it.
